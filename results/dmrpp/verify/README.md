# Verifier verdicts

One CSV per run of `python -m dmrpp.verify --out results/dmrpp/verify/<name>.csv`.
The columns and the meaning of each verdict are in `python -m dmrpp.verify --help`.

Nothing is committed here yet. The runs made up to 2026-11-13 used earlier
versions of the verifier; some of their `MISMATCH` rows were false alarms
that were fixed afterwards, so those runs are to be repeated before their
verdicts are published.
